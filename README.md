# My Terminal UI CV

***Deprecated Project! Checkout [stefvuck.dev](https://stefvuck.dev) for my new portfolio!***

Initially inpsired by [terminal.shop](https://terminal.shop), and not knowing a website framework to correctly match the aesthetic I wanted to go for (before finding [webtui](https://webtui.ironclad.sh/)), I decided to instead bring the portfolio website idea into the terminal, instead of the opposite.

Feel free to use the code and styling yourself, or just check it out yourself. (The myCV binary is made for ubuntu linux)
